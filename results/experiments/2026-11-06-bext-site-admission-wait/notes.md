# Bounded site admission: transient bursts wait before 503

[Bext PR #430](https://github.com/benfavre/bext/pull/430) changes page, buffered API and middleware admission to wait asynchronously for brief contention. Available slots use the immediate path. Each site has at most 256 queued requests by default and each request has 250 ms including time behind other waiters. The queue turn is released before rendering; admitted requests render concurrently. Cancellation frees its queue position. Queue overflow/deadline expiry keeps 503 + Retry-After. Existing fairness rules and pool/PSI caps remain unchanged. `BEXT_V8_SITE_WAIT_MS=0` restores immediate shedding; its maximum is 5000 ms. `BEXT_V8_SITE_QUEUE_DEPTH=0` disables queueing; the maximum is 4096.
